# Simple Calculator Examples

This directory contains the same basic two-number calculator in several languages:

- `index.html`, `styles.css`, `script.js` — browser calculator with keyboard support
- `calculator.py` — Python CLI
- `calculator.rs` — Rust CLI
- `calculator.lua` — Lua CLI
- `calculator.php` — PHP CLI
- `calculator.cpp` — C++ CLI
- `Calculator.cs` — C# CLI

Open `index.html` in a browser for the web version. The command-line versions prompt for two numbers and an operator (`+`, `-`, `*`, or `/`) and handle invalid input and division by zero.
